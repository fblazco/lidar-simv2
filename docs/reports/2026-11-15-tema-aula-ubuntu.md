# Tema Aula Ubuntu

Se añadió `ubuntu` como tercer tema, llamado **Aula Ubuntu** en la interfaz.
Usa superficies color papel, texto ciruela, botones ciruela y acentos Ubuntu
naranja. La paleta del mundo mantiene contraste entre LiDAR, obstáculos,
vehículo, ruta y destinos. El botón de tema recorre claro → oscuro → Ubuntu →
claro; la configuración existente continúa usando claro por defecto.

Se actualizaron las pruebas existentes para incluir la lectura del tema,
contraste, paletas, escenas y ciclo del botón. **No se ejecutaron pruebas en
esta tarea**, por lo que la implementación queda pendiente de verificación.
